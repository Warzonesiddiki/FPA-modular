# 31 — GLOSSARY (single terminology source; UI, docs, exports and AI prompts use exactly these)

Actuals · Accrual — cost recognised before cash/invoice · Adverse/Favourable — variance direction vs plan (always worded, doc 03 §1) · Answer key — planted-exception truth file for acceptance · Batch — one imported file's staged/committed record · Bridge — variance decomposition (volume/price/mix/other) · BvA — budget vs actual · Canonical field — the app's standard import target fields (06) · Close — the month-end process (30) · Commit — atomic move of validated rows into the GL store · Control total — declared totals checked against a file · Cost centre · Cut line — first features dropped if a wave slips (MASTER_PLAN §8) · DQ score — data-quality score (29 §9) · Drill — navigation from a total to its source rows · Driver — operational input (volume, price, headcount…) behind a forecast · Finding — one rule's potential exception on one grain · FVA — forecast vs actual accuracy analysis · Grain — the dimensional level of a comparison (entity×account…) · Locked period/run — immutable, change only via audited unlock/new version · Mapping profile — saved column-mapping for a source format · Materiality — thresholds (absolute AND %) deciding what surfaces · Oracle fixture — hand-computed expected result used as a test · Work item (WI) — one deliverable file + its paired test, the unit of `docs/WORK_PLAN.md`; Milestone (M0–M6) — ordered group of work items with an exit gate (doc 86) · Phasing — spreading an annual amount across months · Potential exception — flagged item for human review (never "error/fraud") · Quarantine — rows held back with reasons, never deleted · Rolling forecast — forecast refreshed as actuals land · Snapshot — frozen input set behind a report · Suspense account — temporary holding account needing clearing · Trial balance — debits = credits proof · Waiver — reasoned, expiring decision to accept a finding/imbalance for now.

Rectification terms (DEC-011/012): Suggested fix — the advisory correcting entry attached to every finding (doc 07 §7); Rectification journal — the per-period file of queued suggested fixes in the ERP's journal-import shape (doc 26 §7; the app never posts) · Correction verification — matching the correcting lines in a later import to move a finding `corrected → verified` · Entry-hygiene rules — EXC-025…028, the rules that read the ledger the way an analyst does (narration vs account, decimal slip, stray cost centre, double billing) · Decimal shift — an amount posted at 10×/100×/1000× (or 1/10…) of the intended figure · Narration token — a normalised word from a voucher description used by EXC-025 (doc 44 §0) · Association table — per-entity counts of narration tokens by account over 12 periods · Anchor (EXC-028) — the earlier of two near-duplicate lines; a flagged line is never an anchor · Posting layer — D365 F&O ledger layer (Current/Operations/Tax/Custom); only `import.posting_layers` enter the ledger · Ledger account (D365) — the segmented account string `main-dim1-dim2…`, split on import and kept verbatim in `source_account_ref` · Vendor enrichment — filling `vendor_id` on GL rows from the AP sub-ledger by (voucher, date) 1:1 match (`vendor_source = ap_match`) · TB tie-out — per-account comparison of an ERP trial-balance export with committed GL (`tb_check`) · Management adjustment — a correction in the app's own layer (doc 39), never in the GL.

Connector terms (DEC-013, doc 26 §8): Connector — the read-only Dynamics 365 integration that pulls a period on the analyst's click · Pull — one execution of job `connector-pull` for one period and set of sources · Snapshot (connector) — the deterministic workbook a pull writes in the preset header shapes; it *is* the import file · Connector profile — data mapping each source to an entity, filter, sort key and field→header map, versioned per project · Entity check — the connect-time verification that every entity and field in the profile exists in the tenant · Source (connector) — `gl | ap | tb | budget | masters` · Delegated / application mode — sign in as the analyst (auth-code + PKCE) vs. a service identity (client credentials) · Watermark — the modified-timestamp field used for "anything changed since my last pull?" (BC `lastModifiedDateTime`) · Allow-list — the only hosts the app may ever contact (`login.microsoftonline.com`, the configured Dynamics host, `127.0.0.1` for the demo ledger) · Demo ledger — `tools/mock_d365.py`, a local emulation of both products serving the sample corpus, used by the first-run walkthrough and every connector test.

Additional terms (alphabetical, same standard): Allocation (doc 40) — spreading shared costs by a rule · Approver — named human who approves commentary/budget/assumptions · Artefact — a generated file (pack, deck, report) with a hash · Backtest — predicting past periods to measure a method · Baseline — the frozen doc/packet set a wave builds against · Budget version — a named, statused budget set · Capex — capital expenditure · Challenger — naive baseline a forecast method must beat or disclose (doc 74) · Control (acceptance) — a case that must NOT fire · Cost centre — responsibility unit for spend · Cut-off — period-boundary timing of recognition · D&A — depreciation & amortisation · Defect severity S1–S4 (doc 72) · DSO/DPO/DIO (doc 43) · Elimination (doc 49, Phase 3) · Evidence — machine/human artefact proving a gate (doc 77) · Favourable/Adverse (doc 03) · Functional currency (doc 50) · Goal seek (doc 29) · Grain (see main list) · Hypercare (doc 82) · Integrity check — DB/audit verification · Layer (doc 39) — GL vs GL+adjustments view · Lock (period/run) · MAPE/Bias (docs 08/46) · Master data · Materiality · Method (forecast) · Migration (doc 61) · Not-run — a rule that lacked inputs and says so · Opex/Capex groups · Owner (finding) · Pack (board) · Pair group (adjustments) · Phasing · Plant (doc 42) · Profile (mapping) · Provenance — stored origin of a value/draft · Quarantine · RAG (with words, never colour-only) · Reclass · Recon (doc 19I) · Rollforward (doc 38) · Run (forecast/rule) · Scenario · Sensitivity · Sign-off · Snapshot · Step-down (doc 40) · Supersede · Tolerance · Trial balance · Waiver · Working capital · YTD/YoY/MoM.
