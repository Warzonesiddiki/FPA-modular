# 31 — GLOSSARY (single terminology source; UI, docs, exports and AI prompts use exactly these)

Actuals · Accrual — cost recognised before cash/invoice · Adverse/Favourable — variance direction vs plan (always worded, doc 03 §1) · Answer key — planted-exception truth file for acceptance · Batch — one imported file's staged/committed record · Bridge — variance decomposition (volume/price/mix/other) · BvA — budget vs actual · Canonical field — the app's standard import target fields (06) · Close — the month-end process (30) · Commit — atomic move of validated rows into the GL store · Control total — declared totals checked against a file · Cost centre · Cut line — first features dropped if a wave slips (MASTER_PLAN §8) · DQ score — data-quality score (29 §9) · Drill — navigation from a total to its source rows · Driver — operational input (volume, price, headcount…) behind a forecast · Finding — one rule's potential exception on one grain · FVA — forecast vs actual accuracy analysis · Grain — the dimensional level of a comparison (entity×account…) · Locked period/run — immutable, change only via audited unlock/new version · Mapping profile — saved column-mapping for a source format · Materiality — thresholds (absolute AND %) deciding what surfaces · Oracle fixture — hand-computed expected result used as a test · Packet (PKT) — one-file agent work order · Phasing — spreading an annual amount across months · Potential exception — flagged item for human review (never "error/fraud") · Quarantine — rows held back with reasons, never deleted · Rolling forecast — forecast refreshed as actuals land · Snapshot — frozen input set behind a report · Suspense account — temporary holding account needing clearing · Trial balance — debits = credits proof · Waiver — reasoned, expiring decision to accept a finding/imbalance for now.

Additional terms (alphabetical, same standard): Allocation (doc 40) — spreading shared costs by a rule · Approver — named human who approves commentary/budget/assumptions · Artefact — a generated file (pack, deck, report) with a hash · Backtest — predicting past periods to measure a method · Baseline — the frozen doc/packet set a wave builds against · Budget version — a named, statused budget set · Capex — capital expenditure · Challenger — naive baseline a forecast method must beat or disclose (doc 74) · Control (acceptance) — a case that must NOT fire · Cost centre — responsibility unit for spend · Cut-off — period-boundary timing of recognition · D&A — depreciation & amortisation · Defect severity S1–S4 (doc 72) · DSO/DPO/DIO (doc 43) · Elimination (doc 49, Phase 3) · Evidence — machine/human artefact proving a gate (doc 77) · Favourable/Adverse (doc 03) · Functional currency (doc 50) · Goal seek (doc 29) · Grain (see main list) · Hypercare (doc 82) · Integrity check — DB/audit verification · Layer (doc 39) — GL vs GL+adjustments view · Lock (period/run) · MAPE/Bias (docs 08/46) · Master data · Materiality · Method (forecast) · Migration (doc 61) · Not-run — a rule that lacked inputs and says so · Opex/Capex groups · Owner (finding) · Pack (board) · Pair group (adjustments) · Phasing · Plant (doc 42) · Profile (mapping) · Provenance — stored origin of a value/draft · Quarantine · RAG (with words, never colour-only) · Reclass · Recon (doc 19I) · Rollforward (doc 38) · Run (forecast/rule) · Scenario · Sensitivity · Sign-off · Snapshot · Step-down (doc 40) · Supersede · Tolerance · Trial balance · Waiver · Working capital · YTD/YoY/MoM.
