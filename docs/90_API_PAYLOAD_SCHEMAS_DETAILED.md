# 90 — API PAYLOAD SCHEMAS, FIELD-LEVEL (normative companion to docs 05 + 63)

> Every field: name, type, required, constraints, example. Money = decimal string (major units), dates ISO, ids per doc 02. Unknown fields in requests are rejected (400 → `FP&A-ERR-002` with `details.unknown_fields`) — silent ignoring hides UI bugs.

## Common
`Page<T>{items: T[], next_cursor: string|null}` · `Job{job_id, status, progress_pct: number|null, stage: string, error: ErrorBody|null, result?: object}` · `ErrorBody{code,message,hint,retryable,details}` (doc 22).

## Projects
`ProjectCreate{name: string 1..80, base_currency: ISO4217, fy_start_month: 1..12, calendar_type: "monthly"}` → `Project{project_id, name, base_currency, currency_exponent (derived, doc 27), fy_start_month, calendar_type, is_sample, periods: Period[]}` · `Period{period_id, fiscal_year, period_no, start_date, end_date, status}`.

## Imports
`Batch{batch_id, source_kind, period_id, file_name, file_sha256, status, row_count_in/valid/quarantined, control: {declared_debit?: string, declared_credit?: string, actual_debit: string, actual_credit: string}|null, mapping_profile_id, committed_at?}` · `QuarantineRow{row_no, sheet, reason (doc 06 §4 enum), raw: object}` · `MappingProfile{profile_id, name, version, is_default, rules: {source_column, canonical_field, transform, constant_value?}[]}` · `SuggestResponse{suggestions: {source_column, canonical_field, confidence: 0..1, basis: string}[]}`.

## Dynamics 365 connector (doc 05 connector routes, doc 26 §8)
`ConnectorStatus{enabled: bool, kind: 'd365fo'|'d365bc'|'none', base_url: string, tenant_id: string, client_id: string, auth_mode: 'delegated'|'client_credentials', company?: string, state: 'not_configured'|'configured'|'signed_in'|'token_expired'|'disconnected', signed_in_as?: string, last_pull?: PullSummary, profile: {version: int, entity_check?: EntityCheck}}` (never contains a token or secret — schema test asserts the field set) · `ConnectorSettingsPut{kind, base_url, tenant_id, client_id, auth_mode, company?, client_secret?: string (write-only; never echoed)}` · `SignInStart{authorize_url: string, port: int}` · `EntityCheck{ok: bool, checked_at: string, missing: {source: 'gl'|'ap'|'tb'|'budget'|'masters', entity: string, field?: string, candidates: string[]}[]}` · `Company{id: string, name: string}` · `ConnectorProfile{version: int, kind, sources: {[source]: {entity: string, filter: string, sort_key: string, watermark?: string, fields: {[entity_field]: preset_header}}}}` · `PullRequest{period_id: string, sources: ('gl'|'ap'|'tb'|'budget'|'masters')[], company?: string}` → job; `PullResult{pull_id: string, status: 'staged'|'no_change', snapshot_sha256?: string, batches: {batch_id, source_kind, rows_in: int, quarantined: int}[], row_counts: {[source]: {expected: int, received: int, pages: int, retries: int}}}` · `PullSummary{pull_id, period_id, status, started_at, finished_at?, row_counts, error_code?}` · `ChangeCheck{changed_rows: int|null, last_pull_at?: string}`. Money never appears in connector payloads (counts only); row data lives in the snapshot file and the import DTOs.

## Statements / BvA / drill
`Statement{statement: "pl|bs|cf", period_id, layer: "gl|gl_adj", lines: StatementLine[], checks: {tb: "balanced|imbalanced|waived"}}` · `StatementLine{line_key, label, amount: string, amount_minor: int (internal-test only, not UI), drill_key: string|null (null = calc line; drill goes via children), is_calc: bool}` · `BvaRow{grain{entity_id, account_id, cost_centre_id?}, actual, budget, forecast?, py?, var_abs, var_pct: string|null, var_pct_reason?, favourable: bool, material: bool, contribution_pct, drill_key}` · `DrillResponse{vouchers: {voucher_no, posting_date, document_date, amount, rows: {description, amount, source_file, source_row, batch_id}[]}[], next_cursor}`.

## Findings
`Finding{finding_id, finding_key, rule_id, rule_plain_name (doc 55), severity, status, amount, entity_id, account_id, period_id, owner: {owner_id, display_name}|null, due_date, evidence: {row_ids: string[], values: object, thresholds: object, grain: object}, suggestion: Suggestion, suggestion_status: 'proposed'|'queued'|'applied'|'exported'|'dismissed', suggestion_ref: string|null, waive?: {reason, expires}, history: FindingEvent[]}` · `Suggestion{kind: 'reverse'|'repost'|'reverse_and_repost'|'reclass'|'reclass_dimension'|'accrue'|'release_accrual'|'clear_suspense'|'move_period'|'investigate'|'commentary'|'none', lines: SuggestionLine[], target_period_id, basis: string, confidence: 'high'|'medium'|'low', erp_hint: string}` · `SuggestionLine{entity_id, account_id, cost_centre_id: string|null, amount: string (decimal, debit +, credit −), description, source_account_ref: string|null}` (doc 07 §7.1; Σ amount = 0 for journal kinds) · `SuggestionApplyRequest{mode: 'adjustment'|'journal'|'dismiss', note?: string}` → `{pair_group_id?: string, suggestion_status}` (ERR-046/005/002) · `RectificationJournal{period_id, lines: (SuggestionLine & {finding_id, finding_key, rule_id})[], total_debit: string, total_credit: string, formats: string[]}` · `TransitionRequest{to_status, note?, waive_reason?, waive_days?: 1..90, reference?}` (guards doc 23 §3 → ERR-040/041).

## Forecast / planning / scenarios
`ForecastRun{run_id, base_period_id, status, created_at, accuracy: {<group>: {method, mape: string|null, bias: string|null, hit_rate: string|null, history_months: int}}, method_map: {<group>: string}}` · `ForecastLine{period_id, entity_id, account_id, amount, method}` · `Scenario{scenario_id, name, base_run_id, deltas: Delta[], status}` `Delta{kind: "driver|pct|absolute", target: string, value: string, period_from?, period_to?}` · `GoalSeekRequest{target_kpi, target_value, driver}` → `GoalSeekResult{solved: bool, value?: string, iterations: int, reason?: string}` · Planning grids (drivers/headcount/capex/debt/wc/cash13) mirror doc 02 §5/§6 tables field-for-field with `value_decimal` strings.

## Adjustments / allocations / assumptions / year-end (doc 05 §4)
`Adjustment{adj_id, period_id, entity_id, account_id, amount, kind, label, reason, pair_group_id?, status, source, created_by}` · `AdjustmentCreate{lines: AdjustmentLine[] (one balanced group), reason: string 1..500, kind}` · `AdjustmentLine{entity_id, account_id, cost_centre_id?, amount: string, label?}` · apply → ERR-042 if Σ ≠ 0 for reclass/closing · `AllocationDef{def_id, name, method, source_scope, receivers: {cost_centre_id, pct?}[]}` · `Assumption{assumption_id, scope, scope_ref?, key, value_decimal, unit, status, version}` · `YearEndClose{fiscal_year}` → `YearEndResult{closing_adjustments: int, opening_batch_id, rollforward_delta_minor: 0}`.

## Exports / commentary / settings / dashboard
`ExportRequest{kind: 'excel'|'pptx'|'pdf'|'journal', period_id, layer?, scenario_ids?, format?: 'd365fo_general_journal'|'d365bc_general_journal'|'generic_csv' (journal only; default = project setting `erp.journal_format`), finding_ids?: string[] (journal only; default = whole queue)}` → Job → `Report{report_id, kind, path, sha256, checks: CheckResult[], snapshot: {batch_watermark, budget_version, forecast_run_id}}` · `CheckResult{name, expected: string, actual: string, delta_minor: int, pass: bool}` · `Commentary{commentary_id, period_id, scope, text, status, ai_assisted, prompt_version?, source_refs: string[], version}` · `CommentaryDraftRequest{scope, refs}` → ERR-070/071 per doc 22 · `SettingsUpdate{key, value}` (doc 62 keys only) · `Dashboard{period, kpis: KpiTile[], close_stages: {key, label, state, blocker_link?}[], top_variances: BvaRow[5], findings_by_severity: object, findings_by_owner: object, forecast_accuracy: object|null, dq_score: {score: int, deductions: {reason, points}[]}, alerts_count: int, unassigned_count: int}` · `KpiTile{key, label, value: string|null, na_reason?, delta_vs_budget?, delta_vs_py?, formula}`.

Field-level parity is enforced by the contract tests (doc 14): the OpenAPI schema generated from routes is diffed against this doc's tables from M3 onward (script in the doc 66 pipeline).
