# 79 — PRICING & LICENSING SPECIFICATION (defaults; owner's commercial DEC finalises)

Default model (fits the offline wedge, doc 32): **perpetual licence per company (project group), one-time fee + optional annual support/updates plan**; trial = full product on sample data + 1 real period, time-boxed 30 days, no feature crippling (trust positioning). Licence enforcement proportionate & offline: signed licence file (Ed25519) checked locally (company name, seats = analyst machines, expiry only for trial/support-plan features like updates — core never expires on a perpetual licence; a lapsed support plan stops updates, never the tool or data access). No phone-home activation (mailed/USB licence file works). Seat transfer via support-issued re-licence. Pricing figures: owner's DEC (record here when set; never hard-coded in app — licence file + config carry them). Anti-patterns banned: per-export limits, data hostage on expiry, dark-pattern renewals (80 §5 claims discipline applies to sales copy).
