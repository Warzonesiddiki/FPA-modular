# 51 — USER STORIES & ACCEPTANCE CRITERIA (Given-When-Then)

> Tests and the UX tabletop (doc 34 stream E) run against these GWTs; FR references doc 19 (ids `FR-<FAM>-<nnn>`). Format per story: As a / I want / so that + GWT. (Representative-complete: every FR family has ≥2 stories; new FRs add stories here in the same PR.)

**US-IMP-01 (P1 analyst)** import a month: Given a committed March and a saved D365 mapping, when I drop April's GL and click Commit, then the mapping is pre-applied, counts reconcile (in = valid + quarantined), and either the batch commits with TB status shown or I get the exact imbalance accounts. **US-IMP-02:** Given a file with 12 bad rows, when validation finishes, then I see 12 quarantined rows grouped by reason with a fix action each, and nothing else was loaded. **US-IMP-03:** Given I re-import a corrected file, when I commit, then row counts equal the new file and the old batch shows Superseded.
**US-CAL-01:** Given a material adverse variance, when I click it, then I see vouchers, then rows, then the source file and row number. **US-CAL-02:** Given budget exists only at entity×account, when I open BvA, then grain is entity×account and the footnote says cost-centre was combined.
**US-EXC-01 (P2 owner):** Given a finding assigned to me, when I open my list, then I see why it was flagged in plain words with the vouchers attached. **US-EXC-02:** Given a false positive, when I waive with a reason for 30 days, then it leaves my inbox and returns automatically if it recurs after expiry.
**US-FOR-01:** Given 24 months history, when I run the forecast, then each group shows its method and backtest MAPE before I can lock it. **US-FOR-02:** Given a locked forecast and new month actuals, when I refresh rolling, then the old run is untouched and FVA shows last month's error.
**US-PLN-01:** Given a hiring plan, when I add 5 joiners in June, then personnel cost and the integrated forecast update and the 3-statement check still balances or names the break.
**US-EXP-01 (P3 CFO):** Given a generated board pack, when I challenge the EBITDA number, then Excel Checks prove it, DrillData shows its rows, and the PPT shows the same figure. **US-EXP-02:** Given a failed tie-out, when I generate exports, then Excel carries the flag and the deck is blocked with the failed check named.
**US-CLO-01:** Given all system tasks complete, when I sign off close, then the attestation, snapshot ids and cycle days are recorded. **US-AI-01:** Given AI on, when I draft commentary, then every number in the draft exists in my variance table or the draft is rejected with the offending number shown.
**US-GOV-01:** Given a changed threshold, when I save, then I saw the impact text first and the change appears in Audit with before/after.
**US-CON-01 (P1 analyst):** Given IT has given me the two IDs, when I enter them in Settings → Connections, sign in with Microsoft and click Test connection, then I see my companies and "All entities found" (or exactly which ones are missing with a picker), and nothing about my sign-in is written to the project file. **US-CON-02:** Given a connected project and a committed September, when I click *Refresh this month* for October, then the GL and vendor transactions are pulled, the D365 preset is already applied, and I land on the same Validate step as a file import with the counts reconciling (in = valid + quarantined) — nothing is committed until I say so. **US-CON-03:** Given nothing changed in Dynamics 365 since my last pull, when I pull again, then the app tells me so and creates no new batch. **US-CON-04:** Given a posting happened mid-pull, when the counts disagree after the automatic retry, then nothing is imported and I am told to try again. **US-CON-05:** Given I click Disconnect, then my sign-in is forgotten on this computer, my settings and pull history remain, and the action is in Audit. **US-CON-06 (first-run):** Given the sample project, when I click *Connect to the demo ledger (local)* with the network cable pulled, then I can pull 2025-P07 end-to-end.
